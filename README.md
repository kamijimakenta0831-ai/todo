# TODO

ブラウザだけで動くシンプルな TODO アプリです。ビルドや依存パッケージは不要です。

## 使い方

`index.html` をブラウザで開くだけで使えます。データはブラウザの localStorage に保存されます。

## 機能

- タスクの追加（期限・優先度つき）
- 完了 / 未完了の切り替え、すべて完了にする
- 編集（ダブルクリックまたは編集ボタン。Enter で保存、Esc でキャンセル）
- 削除、完了済みの一括削除
- 「すべて / 未完了 / 完了済み」の絞り込みとキーワード検索
- 追加順・期限順・優先度順の並べ替え
- 期限切れのタスクを強調表示
- ダークモード対応、スマートフォン幅対応
- 別タブで開いている同じアプリと内容を同期

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | 画面 |
| `style.css` | スタイル |
| `todo-core.js` | データ操作（DOM 非依存。ブラウザと Node の両方で読み込める） |
| `app.js` | 画面の描画とイベント処理 |
| `test/todo-core.test.js` | `todo-core.js` のテスト |

## テスト

Node.js 18 以上で実行できます。

```sh
npm test
```
